Signal

Primary discovery via factory websocket from DEX factory address (when provided). Secondary via GeckoTerminal only when the network slug is confirmed and indexed. Anvil-fork simulation is the primary risk gate; GoPlus support unknown for this chain. Timeboost integration is an explicit stub pending final endpoint disclosure.

Mathematics and Logic

Monitor-first

Same cradle filter and risk-gate semantics as Sol/BSC packages. Live execution disabled until factory address and RPC endpoints are disclosed. Math is identical; only discovery source differs.

Status and Outcome

Experimental (monitor-first). Live execution remains locked by default. Chain ID is user-supplied and must not be assumed. Multiple dependencies on external confirmation (factory addresses, GoPlus indexing, Timeboost endpoints) before any live path.

Failures and Corrections

No documented failures — strategy in monitor-first state with live execution disabled. Design explicitly avoids premature activation by requiring dual confirmation before live enable.
