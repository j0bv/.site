Signal

Backend: gains_momentum_follow via md-collector. Direction: momentum long only (not structural fade). Open on positive r_hat when momentum signal active and depth available. Guard: block_crowded_side_opens — skip if OI skew > 0.60 long.

Exit via structural skew normalization. Optional feed from Solana spot ladder Tier 2 state for cross-strategy signal.

Mathematics and Logic

Chronos2 emits a one-step expected return estimate r_hat at horizon index h. The execution router treats sign(r_hat) as trade direction and gates size with hysteresis:

Hysteresis reduces flip-churn: enter on weaker evidence, exit only on stronger counter-evidence. Calibration uses the tail of |r_hat| from dryrun audit NDJSON — not blind median percentiles when the distribution is bimodal (noise floor ~1e-6 to 1e-5 vs signal tail ~5e-5 to 1e-4 at 30s cadence).

Meme perp universe

Same directional_follow math on Gains-listed meme perps (BONK, PEPE, WIF, DOGE, SHIB). Pair indices resolved at runtime via discovery script. Momentum long when r_hat > R_OPEN and depth available.
