Overview

MoJoe Auto Vinsolutions CRM Integration is an n8n workflow automation system that integrates Vinsolutions CRM with the MoJoe Auto dealership platform. The workflow automates lead import, data normalization, customer record creation, email sequences, and reporting.

Architecture

Data Flow

Vinsolutions CSV/Webhook
    │
    │ Import & Parse
    ▼
Data Normalization
    │
    │ Structure Lead Data
    ▼
Duplicate Check (Firestore)
    │
    │ Filter New Leads
    ▼
Save to Firestore
    │
    ├─→ Create Customer Record
    ├─→ Create Vehicle Record
    └─→ Trigger Email Sequence
    │
    ▼
Update CRM Status
    │
    └─→ Send Notification (Telegram)

Key Components

  • Vinsolutions Webhook - Receives real-time lead data from Vinsolutions CRM
  • CSV File Trigger - Scheduled import (every 6 hours) from Vinsolutions CSV exports
  • Data Normalization - Parses and structures lead data with status/type mapping
  • Duplicate Detection - Checks existing leads in Firestore before import
  • Firestore Integration - Saves leads, customers, and vehicles to Firestore database
  • Email Automation - Triggers welcome emails and status update emails
  • CRM Synchronization - Updates CRM status and maintains data consistency
  • Telegram Notifications - Sends real-time notifications for new leads and daily reports

Workflow Features

Lead Import Pipeline

  • Webhook endpoint for real-time lead ingestion
  • Scheduled CSV file processing (6-hour intervals)
  • CSV parsing with header normalization
  • Data validation and cleaning
  • Lead status and type mapping (Sold, Lost, Active, New, etc.)
  • Lead source tracking (Phone, Walk-in, Website, Import, etc.)

Data Normalization

  • Customer data structure (name, email, phone, address, preferences)
  • Lead metadata (status, type, source, timestamps)
  • Sales person assignment tracking
  • Vehicle information (year, make, model, VIN, stock number)
  • Do Not Call/Email/Mail preference flags
  • Unique lead ID generation based on email, VIN, and timestamp

Automation Features

  • Automatic duplicate detection and filtering
  • Customer record creation in Firestore
  • Vehicle record creation and linking
  • Welcome email sequence triggering
  • Status update email notifications
  • CRM status synchronization
  • Telegram notifications for new leads
  • Daily lead report generation and distribution

Workflow Structure

├── Vinsolutions Webhook

│       └─→ Trigger Status Email
│

    └─→ Generate Lead Report
        └─→ Send Daily Report

API Endpoints

The workflow integrates with the MoJoe Auto API at mojoe-autos.web.app:

  • POST /api/leads/check - Check for existing leads
  • POST /api/leads - Save new lead to Firestore
  • POST /api/customers - Create customer record
  • POST /api/vehicles - Create vehicle record
  • POST /api/email/lead-welcome - Trigger welcome email
  • POST /api/email/status-update - Send status update email
  • PUT /api/leads/update-status - Update lead status
  • POST /api/crm/update-status - Update CRM status
  • GET /api/leads/report - Generate lead report
